# Youngki You — Research Website

This repository contains the source files and rendered output for my personal research website:

**Website:** [https://youngkiyou.github.io](https://youngkiyou.github.io)

The site presents my research experience in structural biology, proteomics, cross-linking mass spectrometry (XL-MS), protein–protein interaction mapping, post-translational modifications, and integrative computational modeling.

## Research themes

- **Munc13-1 structure and membrane recruitment** — ligand recognition, mutagenesis, cellular translocation assays, molecular docking, and membrane molecular dynamics.
- **XL-MS and protein-interaction architecture** — workflow development and integrative analysis of apolipoproteins, photosynthetic microorganisms, and heteromeric acetyl-CoA carboxylase.
- **Post-translational modifications and disease biology** — proteomic studies of carbamylation and other regulatory modifications in cellular and disease-relevant systems.

## Repository structure

```text
.
├── _quarto.yml          # Quarto website configuration
├── index.qmd            # Home page source
├── research.qmd         # Research page source
├── publications.qmd     # Publication list source
├── cv.qmd               # CV page source
├── styles.css           # Custom site styling
├── images/              # Source images used by the website
├── files/               # Public downloadable files
└── docs/                # Rendered website published by GitHub Pages
```

The files in `docs/` are generated by Quarto. Content should be edited in the `.qmd` source files, `styles.css`, `images/`, or `files/`, rather than directly in `docs/`.

## Local development

Install [Quarto](https://quarto.org/docs/get-started/), open the repository folder in a terminal, and run:

```powershell
quarto preview
```

This renders the website and starts a local preview server that refreshes as source files are edited.

To generate the publishable website without starting the preview server, run:

```powershell
quarto render
```

The rendered output is written to `docs/` as configured in `_quarto.yml`.

## Updating the published site

After editing the source files:

```powershell
quarto render
git status
git add .
git commit -m "Describe the website update"
git push
```

These commands rebuild the website, review the changed files, stage them, record a local commit, and upload the commit to GitHub. GitHub Pages then republishes the site from the `docs/` directory on the `main` branch.
